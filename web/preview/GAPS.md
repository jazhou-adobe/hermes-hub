# Design gaps found while building the Feed preview

Contribution list for the design master (`jazhou-adobe/apollo-tokens`, `brands/hermes/design`, built against commit `1d03cf95ad82e400e88e346ff0cb8cb683ee58da`). Source brief: `briefs/command-center-additions.md`.

Run the preview: `bun --port=4800 web/preview/index.html`, then open `http://localhost:4800/`. Surfaces: Feed, Round detail, Answered log, Agents (Roster and Lanes tabs), Settings. Times are fixed at 14:06:20 on 2026-11-20.

**Rule followed:** every missing piece is composed from existing `.hh-*` classes and tokens. Where a piece needs CSS that the design lacks, the rule is in `preview.css` under a `pv-` class (or on an existing class, marked "glue"). No new tokens, no raw values, no new visual language.

## Smaller findings (not in the brief)

- **`data-recommended` has no CSS.** `round-widgets.md` says a Recommended row gets a thick `--hh-recommended` boundary; `hermes-components.css` and the world skin have no `[data-recommended]` rule. Glue rule in `preview.css`; the master stylesheet should add it.
- **`.hh-round[data-state="ended"]` has no CSS** (the docs describe read-only ended Rounds). The preview relies on `fieldset[disabled]` and `readonly`.
- **Timer and progress fills need inline custom properties** (`--timer-fraction`, `--progress-value`, set by `style` in the design's widgets). The Hub's CSP (`default-src 'self'`) blocks `style=` attributes in markup. The preview uses `data-fraction` / `data-value` attribute selectors for the few values shown; the React build must set the properties through the CSSOM (React's `style` prop does) or the master should offer a class- or `data-`-based scale.
- **`.hh-visually-hidden` is `position: absolute`** inside a scrolling `.hh-table-wrap`, which widened the page at 390 px (a hidden header cell at the end of the table). Fix: `.hh-table-wrap { position: relative }` (glue in `preview.css`; belongs in the master).
- **`.hh-icon` has no stroke styles.** The design's `Icon.tsx` sets stroke attributes on every SVG; the preview uses one sprite and a CSS rule (`fill: none; stroke: currentColor; ...`). Worth moving to `hermes-components.css`.
- **Long labels overflow on narrow screens.** `.hh-badge` and `.hh-recommended` are `white-space: nowrap`; "Recommended · applied if unanswered" and "Lock soon · 00:47 to next Lock" widened the page at 390 px. Glue allows wrapping.
- **Muted ink on strip paper.** `.hh-dl dt` and `.hh-hint` use `--hh-muted-foreground`, which fails contrast on `--hh-strip`; a paper variant of `.hh-dl` is composed (`.pv-paper-dl`).
- **`.hh-strip-header` heading inside the Round head** works in the world skin (sentence-case Michroma); the core themes uppercase it, which is long for Round titles. Consider a Round-title role.
- **Big Shoulders is not rendered by the flight-director world** (it sets the condensed role to Michroma), but the manifest ships it for the core themes. The preview loads it only if you switch Appearance to Dark or Light.
- **Icons:** no copy, image, markdown, trash or lock-open icons in the set; `file` and `x` stand in.
- **Glyph `▸`** (brief and spec: "▸ In view") is outside the latin subset and banned as an icon by the contract; replaced by an SVG chevron plus words.
